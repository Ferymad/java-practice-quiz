# Java practice desk

An independent, browser-based Java fundamentals quiz.

Play: https://ferymad.github.io/java-practice-quiz/

- 37 self-contained questions and 164 marks
- A timed 90-minute challenge or untimed practice
- Multiple-choice and code-completion exercises
- Clickable and draggable answers, plus keyboard-accessible selection lists
- Local progress saving and question flags
- Explanations, topic scores and JSON export after finishing
- Responsive layout with no external scripts, fonts or application backend

Topics include data types, declarations, packages, compilation, expressions, object creation and methods.

The answer key is included in the HTML because the quiz runs entirely in your browser. It is designed for self-testing. Progress is saved on your device unless you export it. GitHub Pages processes ordinary website access information under GitHub's privacy policy.

## Run locally

Open `index.html` in a browser. All styles, scripts and question data are embedded. Local-file progress and the hosted site's progress use separate browser storage.

## Hosting

GitHub Pages serves the root of `main`. `.nojekyll` disables Jekyll processing. Updates to `index.html` are published from this branch.
